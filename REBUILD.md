# Как пересобрать графики теплообмена

Температурное поле рассчитываю в [heat_model.py](heat_model.py). Для построения графиков, выгрузки таблиц и проверки точности использую [build_portfolio.py](build_portfolio.py).

## На компьютере

Из папки репозитория, желательно в виртуальном окружении Python 3.12:

```bash
python -m pip install -r requirements-rebuild.txt
python build_portfolio.py
```

Параметры задаются в [model-parameters.json](model-parameters.json): физические величины, сетка, начальный временной шаг, конечное время и допуск. Начальный шаг автоматически уменьшается до выполнения критерия Рунге. Можно передать другую конфигурацию: `python build_portfolio.py --config /path/to/parameters.json`.

## На GitHub

Сохраните изменения параметров или Python-кода в main: **Actions → Rebuild charts** запустится автоматически. Для запуска вручную используйте **Run workflow → main → Run workflow**.

## Результаты и проверки

В `generated/` сохраняются три графика в PNG/SVG: общая иллюстрация, профиль температуры и временная сходимость. Также создаются полное поле CSV, история уменьшения шага CSV, результаты JSON и [отчёт](generated/REPORT.md).

Проверяются конечность поля, выполнение граничных условий, допуск временной погрешности и совпадение осевого профиля с сохранённым результатом при исходных параметрах. [Манифест](generated/build-manifest.json) содержит версии библиотек и контрольные суммы входа, кода и выходных файлов.

Сборка обновляет только `generated/`. При ошибке новые результаты не записываются в main. Результаты для текущих параметров находятся в отчёте сборки. При изменении параметров пересматриваю текстовые выводы отдельно.

Проверка времени не подтверждает пространственную сходимость и адекватность физической модели. Архив результатов каждой сборки доступен в Actions 14 дней. При отсутствии изменений новый коммит не создаётся.
